# Kodem

This repository holds the releases of Kodem. The source code is private.

Download the newest version from [Releases](https://github.com/adamwawrzynkowski/kodem-ade-public/releases). Kodem Nightly releases are marked as pre-releases.

| System | File |
| --- | --- |
| macOS (Apple silicon) | `Kodem-macos-aarch64.dmg` |
| Windows (x64) | `Kodem-windows-x86_64-setup.exe` |
| Windows (Arm64) | `Kodem-windows-aarch64-setup.exe` |
| Linux (x64) | `Kodem-linux-x86_64-setup.run` |

Each file has a `.sha256` file with its checksum. After you install Kodem, it finds and installs new versions of its channel by itself.
